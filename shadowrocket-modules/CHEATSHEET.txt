 5. [Script] — ĐẦY ĐỦ OPTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  tag = type=<TYPE>,
        pattern=<REGEX>,
        requires-body=<0|1>,
        binary-body-mode=<0|1>,
        max-size=<bytes|-1>,
        timeout=<seconds>,
        engine=<script>,
        script-path=<URL>,
        script-update-interval=<0|seconds>,
        argument="<JSON string>"

  TYPE:
    http-request   → Can thiệp trước khi gửi request
    http-response  → Can thiệp sau khi nhận response

  KEY OPTIONS:
    requires-body=1           → Đọc/ghi body
    binary-body-mode=1        → Body dạng binary (protobuf)
    max-size=-1               → Không giới hạn kích thước
    max-size=0                → Chỉ đọc header, không đọc body
    script-update-interval=0  → Không cache, luôn tải mới

 9. CHECKLIST KHI TẠO MODULE MỚI
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  □ Xác định API endpoint bằng proxy tool (Charles/mitmproxy/Proxyman)
  □ Xác định content-type: JSON hay Protobuf (binary)?
  □ Nếu Protobuf → binary-body-mode=1
  □ Thêm hostname vào [MITM] với %APPEND%
  □ Test regex pattern trên regex101.com trước
  □ Luôn gọi $done() cuối script (kể cả khi lỗi)
  □ Thêm try/catch trong JS để xử lý lỗi parse
  □ Escape \/ trong pattern của [Script], KHÔNG escape trong [URL Rewrite]
  □ Test trên thiết bị thật với Debug logging

 10. LỖI THƯỜNG GẶP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ❌ Module không hoạt động:
     → App bật TLS Pinning → thêm force-http-engine-hosts
     → Pattern regex sai → test lại trên regex101.com
     → Hostname chưa có trong [MITM]
     → Script path URL bị lỗi 404
  
  ❌ Body rỗng / null:
     → Thiếu requires-body=1
     → max-size=0 khi cần đọc body
     → Response bị nén (gzip) → SR thường tự giải nén
  
  ❌ Timeout:
     → Tăng timeout=60 hoặc timeout=120
     → Script không gọi $done() → luôn gọi $done()
  
  ❌ 304 Not Modified (body rỗng):
     → Cần xóa ETag/If-None-Match bằng http-request script
     → Xem pattern deleteHeader.js trong repo Locket
